## GitHub Pages Deployment

To deploy ZOYA to GitHub Pages:
1. Go to your GitHub Repository **Settings** -> **Pages**.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Add your Gemini API key in **Settings** -> **Secrets and variables** -> **Actions** as secret name `VITE_GEMINI_API_KEY`.
4. Push to the `main` branch, and GitHub Actions will automatically build and deploy your application.
